# داشبورد یکپارچه مدیریت سازمانی (IMS/HSE/AI)

یک MVP کامل از داشبورد مدیریت سازمانی با تمرکز بر UI/UX مدرن، نمایش داده‌ها و تعامل نرم رابط کاربری.

## ویژگی‌ها

- 🎨 **طراحی مدرن**: تم تیره با افکت‌های نئونی و Glassmorphism
- 📊 **5 صفحه اصلی**:
  - داشبورد فرماندهی (Dashboard)
  - پنل مدیریت فرایندها (IMS Monitor)
  - مرکز پیش‌بینی هوشمند (AI Hub)
  - اتاق کنترل ایمنی (HSE Center)
  - لیگ پیمانکاران (Contractor League)
- 📈 **نمودارهای تعاملی**: Chart.js با انواع مختلف نمودارها
- 🗺️ **نقشه GIS**: Leaflet.js برای نمایش داده‌های جغرافیایی
- 📱 **ریسپانسیو**: طراحی واکنش‌گرا برای تمام دستگاه‌ها
- ⚡ **سریع و بهینه**: React + Vite برای عملکرد بالا

## استک فنی

- **React.js** - فریم‌ورک اصلی
- **Vite** - Build tool و Dev Server
- **Tailwind CSS** - استایل‌دهی
- **Chart.js** - نمودارها
- **Leaflet.js** - نقشه‌ها
- **React Router** - مسیریابی
- **Lucide React** - آیکون‌ها

## نصب و راه‌اندازی

### پیش‌نیازها

- Node.js (نسخه 16 یا بالاتر)
- npm یا yarn

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای پروژه در حالت توسعه

```bash
npm run dev
```

پروژه در آدرس `http://localhost:5173` اجرا می‌شود.

### ساخت نسخه Production

```bash
npm run build
```

فایل‌های بیلد شده در پوشه `dist` قرار می‌گیرند.

### پیش‌نمایش نسخه Production

```bash
npm run preview
```

## داده‌های Mock

تمام داده‌ها از فایل‌های JSON در پوشه `src/data` خوانده می‌شوند:

- `dashboard.json` - داده‌های داشبورد اصلی
- `ims.json` - داده‌های IMS
- `ai.json` - داده‌های AI Hub
- `hse.json` - داده‌های HSE
- `contractors.json` - داده‌های پیمانکاران

## صفحات اصلی

### 1. داشبورد فرماندهی
- کارت‌های خلاصه (4 عدد)
- نمودار ترکیبی (Bar + Line)
- نقشه جهانی
- لیست هشدارهای فوری

### 2. پنل مدیریت فرایندها (IMS)
- نمودارهای عقربه‌ای ISO (3 عدد)
- جدول فرایندهای زنده
- ویجت هشدار گلوگاه‌ها

### 3. مرکز پیش‌بینی هوشمند (AI Hub)
- نمودار پیش‌بینی با Confidence Interval
- باکس تجویز هوشمند
- نمودار دونات تحلیل ریشه‌ای

### 4. اتاق کنترل ایمنی (HSE)
- نقشه GIS تعاملی با Leaflet
- فید زنده با Highlight کلمات کلیدی
- نمودار آنالیز ریسک

### 5. لیگ پیمانکاران
- لیدربرد با مدال‌های طلا، نقره، برنز
- کارت پروفایل تعاملی
- نمودار رادار با انیمیشن

برای اتصال به API واقعی، می‌توانید:

1. فایل‌های JSON را با API calls جایگزین کنید
2. از React Query یا SWR برای مدیریت داده استفاده کنید
3. Context API یا Zustand برای مدیریت وضعیت سراسری
